# muj-vlastni-repozitar
Vítejte v mém osobním deníku z cest po světě!
Tento repozitář slouží jako přehled mých oblíbených cestovatelských zážitků, navštívených míst a praktických poznámek na cesty.
Pro vyhledávání letenek využívám portál [Skyscanner](https://www.skyscanner.cz).
### Moje nejoblíbenější destinace:
* Norsko a skandinávská příroda
* Řecké ostrovy
* Rakouské Alpy
